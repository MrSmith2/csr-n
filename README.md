# CSR-N: Sparse N-Dimensional Tensor Format

## Описание работы

**CSR-N** - формат хранения разреженных многомерных тензоров на языке Python. Формат обобщает идею CSR на случай тензоров произвольного порядка и использует префиксное сжатие координат.

Работа была выполнена в рамках выпускной квалификационной работы и включает реализацию формата, базовые операции тензорной алгебры и экспериментальное сравнение с существующими библиотеками по скорости и потреблению памяти.

## Что реализовано

- Хранение разреженных тензоров произвольной размерности
- Префиксное сжатие координат через структуру дерева общих префиксов
- Представление структуры через массивы NumPy
- Построение формата из COO-представления
- Доступ к элементу по мультииндексу
- Поддержка базовых операций:

  - сложение тензоров
  - умножение тензора на вектор
  - умножение тензора на матрицу
  - свертка тензоров
- Сравнение с `pydata.sparse` и `scipy.sparse`
- Отдельный тест потребления памяти на структурированных данных FROSTT Uber Pickups

## Представление формата

В стандартном COO-формате для каждого ненулевого элемента хранится полный набор координат. Если несколько элементов имеют одинаковые начальные координаты, эти координаты повторяются много раз.

CSR-N решает эту проблему за счет хранения координат в виде дерева общих префиксов. Если у нескольких ненулевых элементов совпадает начало мультииндекса, эта часть записывается один раз, а дальше структура разветвляется только по различающимся координатам.

Физически формат хранится в виде 5 массивов NumPy:

- `indptr` - указатели на диапазоны дочерних узлов
- `base` - смещения для перехода к дочерним узлам или значениям
- `idx` - координаты ребер дерева
- `values` - ненулевые значения
- `level_offsets` - границы уровней дерева

## Эксперименты

В работе проводилось сравнение CSR-N с существующими форматами хранения разреженных данных. Основные метрики:

- время построения формата
- время доступа к элементу
- скорость операций TTV, TTM и TTT
- потребление памяти

Сравнение выполнялось на синтетических тензорах различных размерностей и плотностей, а также на структурированных данных, тензоре Uber Pickups из открытого репозитория [FROSTT](http://frostt.io/)
